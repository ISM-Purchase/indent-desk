# Indent Desk

A single-file browser tool for preparing IIT (ISM) Dhanbad purchase indent documents
(specifications, GeM availability statements, appendices).

## Use
- **Online:** open the GitHub Pages link for this repository.
- **Offline:** download `Indent_Desk.html` and open it in any modern browser.

Your indents are saved only in your own browser (localStorage). Nothing is uploaded.
Use the app's backup/export option to keep a copy.
