# Indent Desk

A browser tool for preparing IIT (ISM) Dhanbad purchase indent documents
(specifications, GeM availability statements, appendices).

## Use
Open the GitHub Pages link for this repository and enter the password.
The app is stored encrypted; it is decrypted in your browser only with the correct password.

Your indents are saved only in your own browser (localStorage). Nothing is uploaded.
Use "Save all as JSON" to keep a backup.
